# VEYRA NIGERIA 🇳🇬 — Luxury Virtual Dressing & Multi-Vendor Fashion Platform

> **The Premier Nigerian Fashion Hub connecting bespoke ateliers and contemporary streetwear brands with an interactive Virtual Dressing Studio, 3D Digital Body Twin sizing, and consolidated nationwide delivery.**

---

## 🌟 Overview

**VEYRA** is a next-generation luxury fashion e-commerce ecosystem specifically engineered for the Nigerian fashion landscape. It bridges the gap between traditional bespoke Nigerian tailoring (*Senator Kaftans, 3-Piece Ceremonial Agbadas, Silk Bubu/Boubou*) and ready-to-wear streetwear (*Heavyweight Fleece Hoodies, Baggy Denim, Kano Handcrafted Leather Footwear, Velvet Fila Caps*).

---

## ✨ Core Features

### 1. 🪞 Interactive Virtual Dressing Studio (`/studio`)
* **Live Cross-Brand Styling**: Mix and match tops, trousers, outerwear, footwear, and accessories across independent Nigerian ateliers.
* **Photorealistic Garment Draping**: Realistic studio lighting, natural layer depth, and ambient shadows.
* **1-Click Outfit Bundle**: Instant multi-brand cart calculation in Nigerian Naira (₦) with bundle savings.

### 2. 📐 3D Digital Body Twin & Bespoke Sizing
* **Custom Body Dimensions**: Height, weight, chest circumference, broad shoulder span, waistline, and trouser inseam.
* **Precision Tailoring Algorithm**: Computes exact size recommendations for Nigerian cuts to eliminate sizing errors.

### 3. 🏬 Dedicated Merchant & Designer Hub (`/vendor-portal`)
* **Isolated Platform Architecture**: Clean standalone portal for bespoke designers and ready-to-wear boutiques.
* **2-Column Garment Studio Publisher**: Direct device/gallery photo upload (drag & drop) with live shopper card preview.
* **Financial & Sales Analytics**: Lifetime revenue breakdown, goods sold matrix, monthly growth bar charts, and customer geography.
* **Paystack Escrow Banking**: Verified NUBAN payouts with automated $T+1$ settlements.

### 4. 👤 Shopper Profile, Orders & Verified Fit Reviews (`/profile`)
* **Mandatory Mobile Numbers**: Seamless phone & WhatsApp routing for Lagos Express & nationwide dispatch.
* **Unified Package Tracking**: Order status timeline (*Payment Confirmed via Paystack* $\rightarrow$ *Consolidated at Veyra Lagos Hub* $\rightarrow$ *Delivered*).
* **⭐ 5-Star Fit Fidelity Reviews**: Real customers rate tailoring quality and shoulder drape.

## 🛠️ Tech Stack

* **Framework**: Next.js 15 (App Router, Turbopack)
* **Language**: TypeScript
* **Styling**: Tailwind CSS, CSS Custom Variables (Luxury Light & Dark Mode)
* **State Management**: Zustand (Persistent Local Storage)
* **Motion & Animations**: Framer Motion, Lenis Kinetic Smooth Scroll, Canvas Confetti
* **Icons**: Lucide React
* **Payment Integration**: Paystack Escrow Simulation

## 🚀 Getting Started

### 1. Clone the repository
```bash
git clone https://github.com/YOUR_USERNAME/veyra-store.git
cd veyra-store
```

### 2. Install dependencies
```bash
npm install
```

### 3. Run the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
